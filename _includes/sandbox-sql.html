Opening it downloads DuckDB (about 10 MB, once) from jsDelivr. Full tables: Hugging Face dataset.

Tables and columns
  • fct_station_hour: station_id, hour_utc, snapshots, avg_bikes, min_bikes, max_bikes, avg_free_docks, share_empty, share_full, share_renting
  • dim_station: station_id, station_name, address, lat, lon, capacity
  • dim_hour: hour_utc, hour_local, local_date, local_hour, weekday, is_weekend, temperature_c, rainfall_mm, wind_kmh, humidity_pct, weather_description

Example queries:

select s.station_name, round(avg(f.share_empty) * 100, 1) as pct_time_empty, s.capacity
from fct_station_hour f join dim_station s using (station_id)
where s.capacity > 0
group by all order by pct_time_empty desc limit 10
select h.local_hour, h.is_weekend, round(avg(f.avg_bikes), 1) as avg_bikes_per_station
from fct_station_hour f join dim_hour h using (hour_utc)
group by all order by h.is_weekend, h.local_hour
select case when h.rainfall_mm > 0 then 'raining' else 'dry' end as weather,
       count(*) as station_hours,
       round(avg(1 - f.avg_bikes / s.capacity) * 100, 1) as pct_docks_without_bike
from fct_station_hour f
join dim_hour h using (hour_utc) join dim_station s using (station_id)
where s.capacity > 0 and h.rainfall_mm is not null and h.local_hour between 7 and 21
group by all
