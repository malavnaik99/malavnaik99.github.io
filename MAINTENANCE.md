# Something broke? Start here

Plain-English fixes for malavnaik.com. Each problem below comes with what it means and exactly what to do.
When in doubt, open Claude Code on this repo and paste what you see. Claude follows `CLAUDE.md`.

**How you hear about problems:** the **Site health** check runs every Monday at 07:00 (Irish time) and after every change.
If something is wrong it opens a GitHub Issue titled `Site health: …` (GitHub emails you if you **Watch** this repo),
updates it while the problem lasts, and closes it by itself once fixed. Issues: https://github.com/malavnaik99/malavnaik99.github.io/issues

## Roll back a bad change

**Fastest, one step (puts the old version live in about 2 minutes):**
1. Go to **Actions → Deploy site to Pages**.
2. Click the last run with a green ✅ **before** the bad change.
3. Click **Re-run all jobs**. GitHub republishes that older version.

This is temporary: the next change to `main` publishes the newest version again. So then tell Claude:
"Roll back the change called '(commit message)' on main", and it will undo it properly (a *revert* commit, so nothing is lost).

## Where things live (for Claude or a developer)
- Identity (name, title, email, bios, profiles): `identity/identity.json`, the single source of truth. `scripts/check_identity.py` stops a deploy that drifts from it.
- Page head, previews, structured data: `_layouts/default.html`, `_includes/schema.html`, `_config.yml`
- Sandboxes and search: `assets/islands/` (one file each, loaded only when needed), data in `assets/data/`. Ctrl+K and the home "Ask" box both use `search.js` over `search.json`.
- Home page projects: the featured Dublin bikes card and the four mixed-colour cards, written in `index.md`.
- Project rows (/work/): `_includes/project-row.html`; each project's row text, headline number, chart and "Try it" link are in its `_projects/*.md` front matter. Charts: `_includes/charts/`, drawn by `scripts/make_charts.py` (automation bars are drawn at build time from `_data/automation.json`).
- Labs (/labs/): the three sandboxes on one page. Each keeps its state in the address (`?t=` threshold, `?q=` question, `?sql=` query) via `window.sandboxState` in `assets/site.js`.
- Home page sky (hero map): `assets/islands/hero-map.js` is the map itself: the projection, the outline lines, the five place labels, the fade under the hero text, and **Explore the live map** (a full-screen `<dialog>` with legend and station tooltips). `assets/islands/sky.js` adds every station from `assets/data/sky.json` (the saved snapshot `_data/sky.json`, made by `scripts/make_sky.py`) and the 48-hour replay. The label words are in `index.md` and the dialog's text in `_includes/sky-bar.html`, as plain HTML so the Gujarati (Google Translate) copy translates them. Live data (on since 16 Nov 2026): `_data/sky_live.json` points at `sky/latest.json` in the Hugging Face dataset `Malavnaik/dublin-bikes-weather-marts`. The `dublin-data-pipeline` repo rebuilds it every hour (`transform.py` → `sky()`, run by its Transform workflow, which the collector starts at :15 past each hour); it leaves out STATION118 and stations reporting 0 docks (Parnell Square North). The page uses it while it is under two hours old, otherwise the saved snapshot; the page itself also drops 0-dock and placeholder stations. Format: `docs/pipeline-latest-json.md`. To switch live data off, empty that `url`. Hourly freshness check: `.github/workflows/sky-freshness.yml` → `site_health.py --only "Bike sky data is old"`.
- Receipts (the four numbers under the hero): click a number to see its dataset, file and test. Text lives in the Receipts table of `docs/METRIC_SOURCES.md`; `scripts/make_receipts.py` copies it to `_data/receipts.json`; the deploy checks they match.
- Hero map outlines (Dublin Bay coast, River Liffey, Grand Canal, Royal Canal, Phoenix Park) and label positions: `assets/data/dublin-outlines.json`, a static file from OpenStreetMap (© OpenStreetMap contributors, ODbL), downloaded once on 16 Nov 2026 and simplified to 20 m; credited under the hero and in explore mode (`_includes/sky-bar.html`). Refresh with `python3 scripts/make_sky.py --outlines` (move a label: edit `LABELS` in that script, then `--labels`). Cloud sessions can't reach overpass-api.de, so run it on GitHub Actions (a one-off workflow, as in git history: "Temporary: download the hero map outlines") or on a computer. The script refuses to save outlines that don't sit where they should beside the stations. The older `_data/sky_river.json` (`--river`) is no longer drawn.
- Street map (Dublin bikes project page, "Station map"): `islands.stationmap` in `assets/islands/sky.js`, same data as the hero sky; Leaflet 1.9.4 is a pinned copy in `assets/vendor/leaflet-1.9.4/` (BSD-2 licence file included); map images from OpenStreetMap (© OpenStreetMap contributors, credited on the map and under it).
- Menu: Work, Labs, Writing, About (+ Résumé), set in `_layouts/default.html`. Toolkit and Journey are sections of the home page (`/#toolkit`, `/#journey`).
- Permits dashboard: `permits-2025/index.html` (figures from `permits-issued-to-companies-2025.xlsx`); its chart library is the pinned copy in `assets/vendor/`.
- Health check: `.github/workflows/site-health.yml` + `scripts/site_health.py` (`python3 scripts/site_health.py` runs it locally)
- Backlinks: `backlinks/README.md` (kit), `backlinks/tracker.csv`, `backlinks/ROUTINE.md`
