Employment Permits 2025 dashboard
Which Irish sectors and employers sponsor work permits, and when – an interactive dashboard built from the official 2025 dataset.
[aria-label] Tech used
Excel
Data cleaning
Chart.js
JavaScript
Tailwind CSS
See it live Code on GitHub
The problem
International students and early-career professionals in Ireland often don’t know which employers actually sponsor work permits, or when in the year hiring peaks.
What I built
A single-page dashboard over the official Permits Issued to Companies – 2025 dataset: total permits, top sector, peak month and top employer, a monthly chart, a sector breakdown and a searchable table of top employers.
How it works
Cleaned the public dataset: standardised company names and grouped companies into sectors.
Aggregated permits by company, sector and month.
Built the page with Chart.js and plain JavaScript, so it loads fast and needs no server.
What I learned
Public labour-market data can answer very practical career questions, if it’s cleaned and presented for the people asking them.
