Malav Naik – Résumé
Data Engineer, GenAI & AI Automation · Dublin, Ireland · malavnaik.com · LinkedIn · GitHub
Download as PDF
Summary
About 10 years in data across India and Ireland: SQL Server and SSIS pipelines, Azure migration, analytics data models, and generative AI (RAG, knowledge graphs, LLM automation). MSc in Data Analytics from National College of Ireland.
Experience
Accenture, Dublin – work for a global technology client
Platform integrity: analysing complex escalations with AI-assisted tools.
S&P Global Market Intelligence – Data Analyst & ETL Developer, 2019–2024
Built SSIS pipelines over multi-million-record financial datasets.
Designed data models for analytics.
Helped migrate on-premise SQL Server databases to Azure SQL Managed Instance, cutting infrastructure costs by about 25%.
Bright Info Solutions, Ahmedabad – Data & reporting
Pulled data with SQL, cleaned it in Excel and Python, and built weekly reports.
Education
MSc in Data Analytics, National College of Ireland, Dublin, 2024–2025. Thesis: Enhanced Personalized Learning Experiences by Leveraging Knowledge Graphs and Prompt Engineering (NCI repository).
Bachelor of Computer Applications, Gujarat, India, 2015.
Selected projects
SkillBot – a skill-recommendation chatbot pairing a fine-tuned GPT-3.5 model with a 2.3-million-triple knowledge graph using retrieval-augmented generation.
More on the work page.
Skills
SQL, SQL Server, SSIS, Azure SQL, Python, data modelling, Power BI, Excel, LLMs, RAG, knowledge graphs, prompt engineering, GitHub Actions.
