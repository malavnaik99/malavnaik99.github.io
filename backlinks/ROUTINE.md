# Your 15-minutes-a-week routine

Do this once a week, ideally on **Monday** (the health check runs at 07:00 that morning, and Peerlist launches happen on Mondays).

## Every week (15 minutes)
1. **2 min: check for problems.** Open https://github.com/malavnaik99/malavnaik99.github.io/issues. No open `Site health:` issue = all good. If there is one, follow `MAINTENANCE.md`.
2. **10 min: do the next 1–2 platforms** from the plan below, using the steps and copy-paste text in `backlinks/README.md`.
3. **3 min: update the tracker** (below).

## Updating the tracker (on the GitHub website, no tools needed)
1. Open https://github.com/malavnaik99/malavnaik99.github.io/blob/main/backlinks/tracker.csv → click the ✏️ pencil.
2. Find the platform's row. Columns are separated by commas; edit only these:
   - `my_profile_url`: your profile address, e.g. `https://peerlist.io/malavnaik`
   - `link_to_malavnaik_live`: `yes` once your profile shows the malavnaik.com link
   - `status`: `todo` → `submitted` (waiting for approval) → `live` (done) or `rejected`
   - `date_done`: today, as `2026-11-12`
   Keep the commas. If a note contains a comma, keep it inside its "quotes".
3. Click **Commit changes…** → message like `Tracker: Peerlist live` → **Commit changes**.

Example of a finished row:
```
Peerlist (profile),Developer profile,https://peerlist.io/,https://peerlist.io/malavnaik,yes,live,2026-11-26,Verified with education.
```

From then on, the Monday health check opens a `Site health: Profile no longer links to malavnaik.com` issue if that profile ever loses the link.

## When to post on Peerlist
- **Launchpad:** Mondays only (UTC day), with a verified profile. One real project every 3–4 weeks, never the portfolio itself. Order: Ask the DSA → moderation classifier demo → SkillBot explorer → Cadentiq (if your co-founder agrees).
- **Regular Peerlist posts ("Scroll"):** whenever a new blog post goes live, at most once a week: one sentence on what you learned plus the link.
- Reply to every comment on launch day; it matters more than the launch text.
