        About the data

        • Rents are the Residential Tenancies Board's average monthly rent for new tenancies registered in each half-year, from CSO table RIH02. They are not what every tenant pays: people in long-running tenancies usually pay less. They are not adjusted for inflation.
        • Gaps are real. The RTB doesn't publish an average when too few new tenancies were registered, so some areas and bedroom counts have no figure for some half-years. Nothing is filled in or guessed.
        • Pay is the median weekly earnings of employees in each county, from CSO table DEA05. Take-home pay is an estimate for one person on PAYE; see "How this is worked out" above.
        • Latest rents: {{ R.latest_label }}. Data last changed: {{ R.site_changed }}. The site checks the CSO for new figures every week.
        • Licence: © Central Statistics Office and Residential Tenancies Board, CC BY 4.0. You're free to reuse these figures with credit.
        • The full cleaned dataset (every property type and bedroom count): Kaggle · Hugging Face · project write-up.

        How I built it

        1. Download. Every week, a free GitHub Actions job fetches two tables from the CSO's open data API: rents (RIH02) and earnings (DEA05).
        2. Clean. A Python script applies the same cleaning as my published dataset: readable columns, blank cells treated as "not published" (never zero), and every place matched to its county.
        3. Check. Before anything goes live it checks the columns, the row count, that every county has a latest figure and that every rent is between €50 and €20,000. If any check fails, the old data stays up and I get an alert.
        4. Publish. It writes one small data file (about 110 KB) and a page for each county. This page is plain HTML and JavaScript: no server, no database, no cookies.
